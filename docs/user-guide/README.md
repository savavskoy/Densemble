# Densemble user guide

This guide is for people who **use** Densemble on their own Mac: how to set up a
feature, what to do every day, and what to do when something goes wrong. Developer
details (architecture, file contracts, tests) live in the main [README](../../README.md)
and [contracts](../contracts.md).
